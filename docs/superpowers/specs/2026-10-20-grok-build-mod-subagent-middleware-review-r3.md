**Recommendations (advisory, do not block approval):**
- **`SubagentLaunched` locals in `Dispatch` (`spec:313-320, 373`).** Step 10 emits `SubagentLaunched` (`handle_request.rs:1662-1677`) and `SubagentCompleted` (`:2459-2480`), which read `queued_for`, `session_running` (destructured at `handle_request.rs:363-364`), and `spawn_timer` (`:388`). Include those three already-in-scope bindings in `mod_adapter::Dispatch` when writing the implementation plan.
- **Unpromoted worktree cleanup (`spec:317, 323, 354-355`).** When `worktree_freshly_created` is `true` and the mod run fails before promotion (`validated: Err(..)` or `!outcome.promoted`), call `crate::session::worktree::remove_subagent_worktree(wt_path).await` just like `cancel_pending_shell_child` does at `xai-grok-shell/src/agent/subagent/mod.rs:2445-2455`.
- **Check in `plugins/cursor/agents.generated/.gitkeep` (`spec:107, 145`).** `PathOrPaths::resolve` checks containment via `dunce::canonicalize(resolved).starts_with(canonical_root)` (`xai-grok-agent/src/plugins/manifest.rs:71-78`). On macOS (where `/var` symlinks to `/private/var`) or symlinked plugin roots, `dunce::canonicalize` on a non-existent `agents.generated/` directory falls back to the uncanonicalized path and fails `starts_with(&canonical_root)`. Keeping `agents.generated/.gitkeep` tracked (while gitignoring `agents.generated/*.md`) guarantees the directory exists at plugin discovery time.
- **Minor comment note (`spec:306`).** `SubagentResult` does implement `Default` at `xai-grok-tools/src/implementations/grok_build/task/types.rs:682`; constructing the full struct literal in `mod_adapter` is still fine and clearer.
